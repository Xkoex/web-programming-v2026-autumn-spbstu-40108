# Лабораторная работа 3

## Задание

Вариант 2. Реализовать функцию `rotateArray(arr, steps)`, которая сдвигает
массив вправо на `steps` элементов. Функция должна экспортироваться как
именованный ESM-export `rotateArray` и возвращать новый массив, не изменяя
исходный.

Пример:

```js
rotateArray([1, 2, 3, 4, 5], 2); // [4, 5, 1, 2, 3]
```
